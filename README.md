# Лабораторные работы по курсу «Криптография»

## 📂 Структура проекта

### 🔹 Лаб1 — GPG шифрование и подпись
Работа с криптографическими средствами защиты информации:
- Генерация и обмен GPG-ключами
- Шифрование файлов симметричным и асимметричным методами
- Создание и проверка цифровой подписи
- Кольца ключей и доверие

**Основные файлы:**
| Файл | Описание |
|------|----------|
| `keys.txt` | Файлы с ключами |
| `script` | Скрипт шифрования |
| `sign_script` | Скрипт подписи |
| `answer.txt` | Тестовый файл |
| `answer.txt.gpg` | Зашифрованный файл |
| `*.asc` | Экспортированные GPG-ключи |

### 🔹 Лаб2 — Факторизация чисел
Факторизация больших чисел с использованием хеш-функции ГОСТ Р 34.11-2012 (Стрибог).
- Получение номера варианта через хеширование ФИО
- Разложение чисел на простые множители
- Анализ вычислительной сложности факторизации

**Основные файлы:**
| Файл | Описание |
|------|----------|
| `create_report.py` | Скрипт генерации отчёта (DOCX) |
| `Cripto2.ipynb` | Jupyter Notebook с вычислениями |

### 🔹 Лаб3 — Сравнение текстов
Сравнение текстов по проценту совпадения букв (5 случаев):
1. Два осмысленных текста
2. Осмысленный текст и текст из случайных букв
3. Осмысленный текст и текст из случайных слов
4. Два текста из случайных букв
5. Два текста из случайных слов

**Основные файлы:**
| Файл | Описание |
|------|----------|
| `main.py` | Основная программа сравнения |
| `text_maker.py` | Генератор случайных текстов |
| `word_maker.py` | Генератор случайных слов |
| `syllable_maker.py` | Генератор слогов |
| `execute.sh` | Скрипт запуска всех тестов |
| `one/`, `two/`, `three/`, `four/`, `five/` | Папки с текстами для каждого случая |

---

## 🚀 Запуск

### Лаб2 — Генерация отчёта
```bash
cd лаб2
python3 create_report.py
```

### Лаб3 — Сравнение текстов
```bash
cd лаб3

# Сравнение двух файлов
python3 main.py one/text1.txt one/text2.txt

# Генерация случайного текста
python3 text_maker.py 100 > output.txt

# Запуск всех 5 случаев
./execute.sh
```
